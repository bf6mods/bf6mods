# Importing an Existing Project

If you want to import an already existing project, Bf6mods makes that easy to do!

## Import from JSON

![Importing from a json file](/images/importing.gif "Importing from a json file")

Export your currently existing project in [portal.battlefield.com](https://portal.battlefield.com), by editing your mod, clicking the three dots on the top right, click export. Finally just run...

```bash
npx @bf6mods/cli import <export file> <output directory>
```
